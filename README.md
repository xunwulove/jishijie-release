# 极视界

自用桌面影视软件，基于 Electron + React。

## 下载

前往 [Releases](https://github.com/xunwulove/jishijie-release/releases) 下载最新版：

- **Jishijie-2.0.2-win-x64.zip** — Windows 64位便携版，解压即用

## v2.0.2 更新内容

- 修复下载管理面板空白问题（接口返回格式不匹配）
- 修复 m3u8 下载取消时 ffmpeg 进程不终止
- 修复 m3u8 文件扩展名错误（.m3u8 改为 .mp4）
- 修复 m3u8 解析不验证内容类型（HTML错误页不再被误解析）
- 修复 URL fragment 导致扩展名识别错误
- 播放页新增下载当前集按钮
- 详情页新增线路可用性自动探测（绿点=可播，红点=失效）
- WebView 嗅探加 30 秒超时
- 修复重试后下载完成通知丢失

## v2.0.1 更新内容

- 新增线路可用性自动探测
- 播放页新增下载按钮

## v2.0.0 更新内容

- 新增视频下载功能：支持直链 mp4 和 m3u8 切片下载
- m3u8 原生切片下载器：5并发、AES-128解密、断点续传、自动选择最高码率
- 下载管理面板：设置 → 下载，支持取消/重试/删除
- 详情页和播放页均可下载单集或全部剧集
- 下载完成/失败全局通知
