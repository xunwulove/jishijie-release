# 极视界

自用桌面影视软件，基于 Electron + React。

## 下载

前往 [Releases](https://github.com/xunwulove/jishijie-release/releases) 下载最新版：

- **Jishijie-2.0.1-win-x64.zip** — Windows 64位便携版，解压即用

## v2.0.1 更新内容

- 新增线路可用性自动探测：详情页打开后自动检测各播放线路是否可播
- 线路按钮前显示状态圆点：绿=可播，红=失效，黄=磁力，灰=探测中
- 播放页新增下载当前集按钮

## v2.0.0 更新内容

- 新增视频下载功能：支持直链 mp4 和 m3u8 切片下载
- m3u8 原生切片下载器：5并发、AES-128解密、断点续传、自动选择最高码率
- 下载管理面板：设置 → 下载，支持取消/重试/删除
- 详情页和播放页均可下载单集或全部剧集
- 下载完成/失败全局通知
